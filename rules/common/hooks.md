# Hooks System

Project-specific hooks can be configured in `.claude/hooks/hooks.json` at the project level or `~/.claude/settings.json` at the user level.

The project-orchestration plugin provides hooks for dispatch logging — see `hooks/hooks.json` in the plugin directory.

---

This file is universal. Extended by `typescript/hooks.md` for TypeScript-specific hook conventions. Where that file conflicts with this one, the more specific file wins.
